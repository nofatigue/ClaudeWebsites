# האתרים שלנו

ריפו אחד, כמה אתרים סטטיים (HTML/CSS/JS, בלי build), מוכן ל־GitHub Pages.

- `index.html`: **פורטל** שמוביל לכל האתרים
- `habayta/`: **נוסעים הביתה**, מדריך לצעירים שרוצים לחסוך, לתכנן ולקנות דירה בישראל
- `chizuk/`: **נקודה טובה**, עצות מהחסידות לעבודת ה׳ ולעשיית טוב (פרטים בהמשך)

כל אתר מקשר בתחתית חזרה לפורטל. להוספת אתר חדש: תיקייה חדשה + כרטיס ב־`index.html`.

# נוסעים הביתה (`habayta/`)

אתר בעברית לצעירים שרוצים לחסוך, לתכנן ולקנות דירה בישראל, או לחיות אחרת.

## מבנה
- `habayta/index.html`: עמוד הבית + מחשבון "כמה זמן ייקח לחסוך"
- ציר 1, עקרונות יסוד: `basics.html` → `save.html`, `finance.html`, `buy.html`
- ציר 2, דרכים אחרות: `alt.html` → `alt-live.html`, `alt-rent.html`, `alt-grants.html`
- ציר 3, טריקים במשפט: `tricks.html` (הטריקים עצמם ב־`assets/tricks.js`)
- `habayta/assets/app.js`: כותרת, תחתית וכל המחשבונים. **שם האתר נקבע כאן (`SITE_NAME`)**
- `habayta/assets/style.css`: עיצוב (כולל מצב כהה)

## עקרון מנחה
פשטות: עד 3 נקודות ראשיות בכל עמוד, וקישורים לעמודים אחרים.

## הרצה מקומית
```
python3 -m http.server 8080
```

## פרסום
Settings → Pages → Deploy from a branch → בחרו את הענף ואת התיקייה `/ (root)`.

# נקודה טובה (`chizuk/`)

אתר נפרד בתיקייה `chizuk/`: עצות מרבי נחמן, חב״ד וצדיקי החסידות לעבודת ה׳ ולהתחזקות בעשיית טוב.
- `chizuk/index.html`: העצה של היום, "מה עובר עליך?", ומעשה טוב יומי עם רצף
- `chizuk/etzot.html`: כל העצות, עם סינון לפי נושא ומקור, חיפוש ו"העצות שלי"
- `chizuk/about.html`: על האתר והמקורות
- `chizuk/sources.html`: מאגר המקורות, עם הנוסח המקורי, קישור לספריא ומצב בדיקה
- **מאגר המקורות ב־`chizuk/assets/sources.json`**: כל מקור עם מזהה, ספר, מיקום, נוסח מקורי, קישור לספריא ו־`status` (`verified` / `secondary` / `tradition`). כל עצה מפנה אליו דרך `refs`, וכל `<a data-src="id">` בעמוד מתמלא אוטומטית בקישור למאגר. (המאגר נטען ב־fetch, לכן צריך שרת ולא file://)
- **התוכן כולו ב־`chizuk/assets/data.js`**: עצות (ETZOT), נושאים, מצבי רוח ומעשים טובים. להוספת עצה מוסיפים אובייקט לרשימה; `free: true` מסמן "בלשון חופשית".
